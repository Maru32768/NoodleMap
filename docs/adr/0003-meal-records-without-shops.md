# 店舗に紐づかない食べた記録を許す

ラーメンフェスには、登録店舗に紐づかないブースが出る。たとえば日本ご当地ラーメン総選挙の「酒田ラーメン」は、ページに運営店舗の記載がない。これを記録するために店舗を登録すると、地図上の1軒という店舗の定義が崩れる。

食べた記録の提供店舗を0軒以上に改める。提供元を表す新しい項目は足さず、ブース名は公開メモやメニュー名に書く。

店舗が0軒の記録は催事・出店先を必須とする。店舗も出店先もない記録は、全記録一覧には出るが、編集できる画面がどこにもなくなるからだ。管理者は出店先ページの「記録を管理」から、出店先の入った状態で記録を追加・編集・削除し、画像を管理する。店舗の件数、お気に入り度、代表写真は店舗との関係から導くため、店舗のない記録はどれにも影響しない。カテゴリを持たないので、全記録一覧でカテゴリを絞り込むと表示されない。
